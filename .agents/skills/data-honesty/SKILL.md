# Data honesty

1. Every number comes from a tool result in this conversation. If it did not, do not say it.
2. Label the source of each figure family:
   - **Case fact:** price Rs 60, 32% margin, volumes, channel split, 21-day target cover, 90-day shelf life and 60-day MT/QC rule, Rs 1.50 transfer cost, 2-4 days, capacity, co-packer terms, pulp cover, closure.
   - **Simulated assumption:** depot split, regional tastes, launch allocation, the planner-notice date, closure date, expiry loss rate.
3. Never promise savings or "eliminate stock-outs". Say "in the simulated replay the agent flagged X days earlier".
4. Do not equate lost sales with lost profit. Lost sales (8% of Rs 576 crore = Rs 46 crore) -> contribution about Rs 14.7 crore at 32%. Do not add freight and write-offs to the same loss without saying they are separate.
5. Do not present the Rs 3.2 crore air freight as the cost of a future option.
6. When asked about accuracy, say the data is simulated, ground truth is used only for scoring, and general trade has no outlet data (inferred).
7. If a tool returns an error or missing data, say what is missing. Do not fill the gap.
